# Interactive Resume Builder

A responsive and interactive Resume Builder created using HTML5, CSS3 and Vanilla JavaScript.

The application allows users to enter their personal information, education, experience, skills and projects while viewing a live formatted resume preview.

---

## 🚀 Features

- Live resume preview
- Personal information form
- Professional summary
- Skills section
- Dynamic education entries
- Dynamic experience entries
- Dynamic project entries
- Add and remove education entries
- Add and remove experience entries
- Add and remove project entries
- Responsive design
- Print-friendly resume
- Save resume as PDF using browser print
- Clean and professional UI
- No external frameworks required

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Print Media Queries
- DOM Manipulation
